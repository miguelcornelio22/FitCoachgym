# 🏋️ FitCoach - Agente de Rutinas de Gimnasio

## 📌 Descripción
FitCoach es un agente conversacional que genera rutinas de gimnasio personalizadas según:
- Nivel de entrenamiento (principiante, intermedio, avanzado).
- Grupos musculares seleccionados.
- Tiempo disponible en minutos.

El agente utiliza **Pandas**, **Regex**, **Pydantic** y **Streamlit** para procesar datos estructurados y ofrecer una interfaz web interactiva.

---

## ⚙️ Tecnologías utilizadas
- **Python 3.13**
- **Pandas** → manejo de datos en CSV.
- **Regex (re)** → extracción de patrones en texto libre.
- **Pydantic** → validación y tipado de datos.
- **Streamlit** → interfaz web interactiva.
